# 本次增强实验设置

日期：2026-10-24。

1. Jetson真实腕部相机：640×480，图像逆时针90°；记录主机取帧时间，不能视为传感器曝光时刻。
2. 部署同版本YOLO26n检测和深度模型，对照PyTorch FP32、FP16与TensorRT FP16。引擎由Jetson本机编译，不修改an-project安装包。初次矩形输入测试仅作冒烟；正式对照固定640×640填充，并使用相同保存帧。
3. Jetson Qwen使用已有Qwen3-VL-2B NF4模型与已有独立加载依赖，不加载其他项目LoRA。与PC端4B模型不作同模型压缩前后结论。每次推理完成后选择最新主机接收帧，不排队累计帧。第一轮排除模型加载并单列预热；记录生成token数、输入帧年龄、推理耗时和CUDA内存。
4. PC策略扩展：原66条示教及54/6/6划分不变；训练种子20261024、20261025，各10000步，每2000步在1500–1505六个新布局×六任务验证。固定按成功数最多、同分验证L1较低、完全同分较早选模；同时保存验证L1最低模型。1600–1607八个新布局×六任务仅最终测试，不据测试结果调选模规则。此处扩大验证与重复种子，不宣称增加训练数据或真实执行能力。
5. 默认不连接电机驱动。后续若开展实体运动，需要用户另行确认固定、活动空间与停止方式。单目预测深度未经标定，不用于直接发送抓取坐标。
