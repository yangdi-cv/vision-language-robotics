# VLA 独立工作台

启动：`perception/vla_workbench/start`；访问 <http://127.0.0.1:8081/>。

旧工作台 <http://127.0.0.1:8080/> 保留，必须先运行。新服务代理它的RGB/深度流和Qwen输出，不重复打开相机，也不修改旧页面。

右下角将IMU替换为SmolVLA：任务输入、预测耗时、对应帧年龄、50步动作曲线、六关节输入状态及预测首步。连续处理最新图像，固定初始噪声以便观察输入变化的影响。任务更新在下一轮推理生效。

SmolVLA单独使用 `.venvs/smolvla` 和固定基础权重。沿用 `experiments/smolvla_pc/README.md` 的临时归一化与相机映射，尚未验证本机动作适配。当前串口由独立保持程序占用，本页明确使用最近一次小步试动后的前五关节快照、此前夹爪读数，显示快照年龄；不是实时关节反馈。若机械臂被移动，输入状态会失效，本页仍不执行动作。

本服务没有电机执行API、不调用遥操作、不发送串口指令。关闭新页面或新服务不会停止外部保持程序、不会关闭外部控制器启用的扭矩；其状态应单独管理。旧页面的控制按钮保留在旧页面。

推理日志与输出在 `records/smolvla_live/时间戳/`。正常停止新服务按启动终端Ctrl+C；只会结束本服务和SmolVLA工作进程，保留8080工作台和外部控制器。

已验证真实相机共享、Qwen与深度代理、SmolVLA连续输出及浏览器布局。结果每轮约0.15～0.17秒，未作为正式性能基准。预测变化不等于指令正确执行。

更新：独立受限试动程序已发布实时关节读数到 `experiments/smolvla_pc/runs/joint_latest.json`。新网页模型进程优先使用1秒内的新鲜反馈，并显示“实时关节”；无新鲜反馈时明确标为快照。网页本身仍无电机执行API，外部试动程序结束后保持扭矩，需要托稳后发送OFF。
