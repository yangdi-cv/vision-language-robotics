# Dependencies and assets

- Robot/table meshes and original end-effector scene: gym-aloha0.1.1, Apache-2.0, https://github.com/huggingface/gym-aloha . The modified scene is generated by `scripts/task.py`.
- ACT implementation: local vendor-derived LeRobot0.3.4, Apache-2.0; source and license are included under `SO101/code/lerobot` in the code archive.
- Qwen3-VL-4B-Instruct: https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct , pinned revision `ebb281ec70b05090aa6165b016eac8ec08e71b17`. The large base weights are not redistributed in the code archive.
- Demonstrations in this experiment are generated from scripted physical simulation. They are separate from the public ALOHA transfer dataset used in the earlier experiment.
