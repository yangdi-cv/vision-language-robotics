# 耳机壳拾取与鼠标垫放置示教

三条完整遥操作记录：竖直出发，拾取蓝色耳机壳，放到黑色鼠标垫，松开退离，回到竖直。任务成功为操作人员报告，抽样图像可见各阶段；未据图像推断所有帧均无接触或无碰撞。

原始目录 episode_01/02/03 保留不变。临时腕旋转−90°已经包含在动作中，不要再次叠加。前五关节单位度，夹爪百分比；state为实际读取，action为当轮实际发送绝对目标。每条独立相机640×480原始方向，名义10Hz。时间戳为主机接收时刻，不是曝光时刻。

`prepared_v1` 只保存训练索引及审查图，不移动或删除原图。裁剪采用五臂关节1秒内变化超过5°，排除最初启动对齐，并向前后各留约2秒上下文。三段训练范围为第一条339–642、第二条29–313、第三条44–354（闭区间）；应以audit.json实际记录为准。完整保留竖直上下文、接近、抓取、搬运、释放与返回，不仅截取抓放。

训练预处理为保持比例缩到256像素并黑色填充为256×256。评估时使用相同处理，不能直接换回旧512配置。首轮前两条训练、第三条整条留出，归一化仅在训练集统计；最终三条合训时，第三条结果只能称训练内拟合检查，不能继续叫留出验证。

三条数据很少、指令单一、背景和硬件固定，无法据此验证语言泛化、换场景泛化或稳定成功率。
