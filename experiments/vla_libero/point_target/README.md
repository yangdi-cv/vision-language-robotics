# 显式目标图与同场景双目标数据：有界尝试

目标：检验额外带红框的初始参考图能否帮助π0.5按指定对象执行。参考Point-VLA的固定参考图+当前多视角、文字/目标图共训练；结合Shortcut Learning研究中的打破场景固定关联思路。不是官方Point-VLA训练代码/权重复现。

原始当前agentview和腕部相机不改；把原来空置的right_wrist_0_rgb槽位用于参考图，视觉指定时mask为真。文字模式保持原mask为假，输入变换已验证与原始变换逐项一致。目标框来自仿真分割，只是准确目标定位的能力上限；不能声称实现了Qwen视觉定位或真机自主指物。

数据：原训练初态20–25/验证26–27的成对合格教师示教，加新训练36–39、验证40，正常与重置时交换XY位置两布局。每对必须两个指定目标都通过最终稳定放置与另一件全程位移<=30毫米的验收。脚本教师用于造训练数据，不计为VLA成功。物体交换只发生在初始化，控制中不改qpos、不搬动物体。

试验：1000步batch2零B初始化LoRA，仅语言/动作专家LoRA参数可训练，FP32主参数，基座/视觉冻结。文字与目标图batch精确1:1；每batch同布局的相反目标，40%采共享观察分叉点，60%分阶段。本地新增增强仅将参考图与目标框同步平移，当前原始相机输入不改；官方训练预处理仍保留其当前相机裁剪/旋转/颜色增强，目标参考槽位保留官方wrist颜色增强。验证固定样本，选择200/600/1000中的最低验证损失。

新初态41：两任务×两布局×两指定目标8条件，比较原权重、同一适配权重的文字模式、目标图模式，共24回合；42预留，不根据41结果再扩训练。原始任务公开方案的6回合实例单列在../official_instance，不与本试验混算。

入口：scripts/prepare.py（教师与成对筛选）、layout.py（重置交换与准确框）、goal_inputs.py（共享变换）、train.py、evaluate.py、advance.py（隔离限额依次运行）。scripts/visual_prompt.py有3项图像标记测试。预检检查RGB方向、目标框、原图保持和mask；曾因要求缓存RGB与当前渲染逐字节相等而中止，随后检查方向误差并核验原图/分割空间对齐。没有降低对象可见性要求，4张预检图均保留可视检查。

运行：模型任务沿用../skill_bootstrap/scripts/python_model.sh及独立systemd用户单元14/16GiB软硬上限；CPU数据进程4/6GiB。不在编辑器进程组加载大模型、不改Swap，不连实体机械臂。当前状态见DATA_STATUS.json、training/STATUS.json及evaluation/*/STATUS.json；不能把训练损失下降当成目标选择改善。

注意：适配后的文字/目标图使用同一权重，是输入方式对照，不是两套独立训练的消融；它不能单独分离增加数据、位置交换与联合训练各自的贡献。
