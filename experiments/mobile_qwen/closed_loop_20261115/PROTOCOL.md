# 可供性驱动预接触：冻结验收

2026-11-15。PC仿真，不连接机械臂，端侧性能优化暂缓。

链路：同一MuJoCo世界 →（Nav2停靠）→ RGB把手定位 → 仿真真值深度反投影 → 世界/机器人坐标转换 → 已知姿态和偏移的预接触模板 → MoveIt/KDL/OMPL → FollowJointTrajectory → 受限力矩关节PD → RGB重观测。

开发控制器：最初140/20末端关节误差超容差，保留失败；在oracle开发回合上改400/40后到位，之后所有模式固定相同400/40。速度/加速度缩放0.12，原模型力矩限幅，轨迹插值20Hz、底层MuJoCo物理子步。终止关节容差0.015rad，额外保持1.5s，不改qpos凑结果。

高层4B BF16，同一个加载的PEFT模型用disable_adapter上下文切换base/lora，记录并断言真实适配状态；提示词与既有定位评测一致，40新token贪心。GT oracle仅作明确上限，不混入模型结果。未训练新LoRA、未修改原权重。

预接触模板：把手3D点加世界偏移(-0.12,-0.10,+0.10)m，姿态沿用初始TCP；这是约18.5cm斜前上方的预接近，不是6D抓取或触碰把手。点是模型决定的，偏移/姿态是技能先验。深度与碰撞地图来自已知仿真，非真实RGB-D/SLAM。

模型模式到位后重新观察并预测；以当前TCP到新预测预接触目标的距离<=25mm确认，最多一次重新规划。官方真值目标只做事后评分，不决定修正或停止。成功需真值预接触误差<=30mm、无外部接触/自碰撞、同一物理实例；oracle无视觉确认单独评分。原LIBERO任务成功通常为false，因为没有执行入抽屉/关门，不能将预接触成功称整任务完成。

开发回合nominal初态0用于贯通功能；之后冻结参数。扰动定义为初始化前固定相机在自身横轴/竖轴平移3cm，更新真实相机标定；没有物体/机器人运行时瞬移。所有50初态已有使用历史，新的相机扰动仅称未用于训练的视角条件，不称全新初态或跨场景。

后续同配对条件比较oracle/base/lora，分别记录导航成功、MoveIt计划/实际控制成功、预测误差、事后真值到位误差、重观察次数/残差与碰撞。缺失或拒绝算失败，不用事后真值挑选成功回合。MoveIt退出析构问题另计cleanup_ok，不伪称清理已修复。
