# 第一条示教：深蓝色塑胶壳移动到标记区

## 状态

软件采集、保存、重新加载、质量检查和观察视频导出已通过无机械臂运动测试。测试使用真实相机及合成关节数据，仅存在临时目录，不属于真实示教成果。

第一条真实示教尚待用户准备物体与相机视角。确认是空塑胶壳，移除耳机及充电盒；取一个夹爪容易夹持的位置。用纸或胶带定义桌面放置区，第一轮先不要求放入深容器。

## 启动

关闭占用相机和机械臂的预览/遥操作程序。确认底座固定、工作区清空、供电正常且能随手断电，支撑从臂。

```bash
/home/yd/Documents/VLA/SO101/code/scripts/ubuntu/start-record
```

程序先检查相机，在终端等待回车；确认准备好后回车，程序核对校准，连接主从臂并开始记录。缓慢操作黑色主臂，让白色从臂夹起塑胶壳并放到标记区。完成后将白色臂放到有支撑的位置，按 Ctrl+C，等待数据保存后再关闭终端。

启动脚本现在默认开启同步画面窗口，显示的就是保存的图像。关闭该窗口也会停止并关闭扭矩，因此先托稳从臂。不要另开独立预览或 Qwen 相机窗口占用同一设备。

异常运动直接断开 12V 电源；不要为了保存记录延迟停止。

每次启动在 `SO101/datasets/pilot_时间_进程号` 新建一个 episode。不会上传数据，也不会覆盖既有数据。短试采用于检查链路，不直接用于宣称策略训练或任务成功率。

## 检查与回放

用启动时打印的实际数据目录替换下面的路径：

```bash

  /home/yd/Documents/VLA/SO101/code/scripts/review_demonstration.py \
  /home/yd/Documents/VLA/SO101/datasets/pilot_实际目录
```

输出 `quality.json` 和 `observation_preview.mp4`。视频只是观察图像回放，不向机械臂发送动作。人工检查夹起、搬运、放置是否完整，相机是否一直看到物体及夹爪；失败示教保留但明确标注，不默认视为成功样本。

## 数据语义与限制

- 相机固定在机身，预览与采集默认逆时针旋转 90°（顺时针 270°），保存图像为宽 480 × 高 640。两者可用 `--rotation 0/90/180/270` 覆盖，采集角度写入 `session.json`；正式数据须保持配置一致。回放使用已旋转保存的图像，无需二次旋转。相机会随臂姿态改变视野。

- 沿用已验证遥操作参数：10 Hz，五个关节使用度，夹爪使用百分比；每次目标距当前位置最多 5 个相应单位，肩 P=28、肘 P=24，退出恢复为 16 并关闭扭矩。
- LeRobot v2.1 图像数据格式，关节状态、实际发送的绝对目标动作、RGB 图像和任务文本；不使用视频编码采集以减少首轮依赖。
- 标准数据时间戳为 frame_index/10；`timing.csv` 独立保存主机收到状态、图像及发送动作的 monotonic 时间。
- 相机与状态顺序读取，尚未做硬件同步；图像接收时间不是曝光时间。循环间隔异常不等同于已测得摄像头丢帧。
- `session.json` 保存单位、顺序、串口、相机与校准校验和。结束后状态为 review_required，须人工确认任务结果。
- 文件写入与图像采集可能降低实际频率，用实测周期评估；尚未验证运动中性能。
- 此阶段每条记录一个独立数据集；批量采集、数据集合并和 episode 重录管理后续实现。
