# 本地网页工作台

启动：

```bash
/home/yd/Documents/VLA/perception/web_workbench/start
```

访问 http://127.0.0.1:8080/ 。仅监听本机，硬件与4090推理都在此工作站，不部署到远程站点。

## 页面与操作

- 实时旋转RGB、检测框及深度图、Qwen自然语言结果。
- IMU薄板3D嵌入同一页面，复用8000端口已有服务；如服务未运行，工作台尝试启动唯一IMU读取服务。默认前向+Z、LED端+X，支持切换。
- 启动自动加载Qwen/YOLO，连续处理最新帧，不积压请求。
- 主从操作需明确确认固定、空间、电源停止方式后启动。停止前托稳白色臂；异常运动直接断开12V电源。
- 页面关闭、刷新或控制心跳丢失超过4秒会中断主从控制，退出关闭扭矩。操作时先支撑从臂再离开页面。
- 模型只观察，不能产生运动指令。

启动前关闭旧Tkinter窗口、独立预览、示教采集与独立遥操作，避免相机/串口争用。已有IMU独立窗口无需关闭，不会重复读取串口。当前网页未合并训练数据采集。

后台正常退出按启动终端Ctrl+C。启动脚本使用现有观察环境与dialout组。旧Tkinter代码保留备用。

## 自适应深度显示

仅保留最初的逆深度2–98百分位自适应拉伸，恢复场景对比，图像顶部与左侧RGB对齐。颜色逐帧变化，不能跨帧用同色比较距离。米制图例为模型估计，框内深度仍可能包含背景。固定0–3m选项已从网页移除。

IMU嵌入右侧场景观察卡片下方，显示黑色4:5板卡、浅色背景和原始姿态数值，隐藏所有设置并固定前向+Z、LED端+X。独立IMU页面仍保留调试设置。

顶部默认中文，可切换English；标题、状态、确认对话框和IMU状态随之切换，Qwen下一轮也输出英文描述。切换期间显示等待新语言结果，不把旧中文冒充英文。

## 数据与验证

会话在 `records/scene_understanding/web_时间戳/`，保存Qwen输入/输出、最新深度与元信息、时间记录及控制日志。

已验证真实相机、Qwen/YOLO运行、两种MJPEG流、浏览器布局/图例切换、嵌入IMU实时状态。运动API要求本机会话令牌、同源与确认；无令牌或未确认启动被拒绝。心跳丢失中断以模拟进程测试通过，网页QA未使能机械臂。

网页主从操作仍待用户确认后试用，迁移不等于新的策略或控制性能实验。
