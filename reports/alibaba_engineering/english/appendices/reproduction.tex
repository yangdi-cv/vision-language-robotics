\chapter{Running and Directory Examples}

This appendix retains runtime and directory snippets from each phase. They correspond to historical environments and data and should not directly overwrite existing outputs; rerunning should use a new experiment identifier and prepare the required weights and data from the original project. These models, simulations, or physical commands were not executed during the writing of this paper.
