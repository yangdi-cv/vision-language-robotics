# 训练前数据审核

验收阈值、初态划分及训练上限保持PROTOCOL.json不变，以下修正在查看模型测试结果前完成。

- 第一批配对图已人工查看篮子与白杯的居中、偏心、悬空和近接触样例。近接触图与成功图常常肉眼相近，保留unknown，而不强迫视觉模型复现毫米级阈值。
- In等区域谓词本身不足以排除物体仍在空中。正式样本同时记录非机器人支撑接触与夹持状态，完成真值要求关系、支撑及释放；悬空不因仍在区域包围盒内就标完成。
- 两个相同摩卡壶用“a/another”及参考图中已放好的数量描述，避免用不可见物体ID指定身份。几何和分割仅用于造数核验。
- 同一组增加另一件物体已经放好的上下文，覆盖第二个子目标的起始状态。
- 目标被遮挡到只剩很少可见像素时，训练答案改为unknown，真值独立保留。分割、接触和几何只用于造数及审核，不进入推理输入。
- 实际夹持图来自独立的非Long轨迹，使用双指接触验证；同一源回合整体放入一个集合。Long0–2的检查图只作后续部署诊断。

实例分割预检查发现碰撞几何与渲染几何不是同一组ID，首份可见性统计因只匹配碰撞几何而全为零。审核程序阻止了训练；修正为同时匹配visual/contact几何，重新生成正式计数，并保存每个反事实的物理快照便于独立复核。此前数据索引归档，不用于模型训练。

开发验证中还发现float32的yes概率存在饱和到1的并列值（基座验证集11例），会丢失阈值排序。最终校准统一改用原始三类logits的float64 log-odds，基座与adapter完全相同；仅用验证集选阈值，测试集仍未打开。JSON序列SFT与直接分类开发轮均归档，最终权重按验证集选择。
