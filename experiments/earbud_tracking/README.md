# 耳机壳视觉追踪

复用自采数据训练的YOLO26n，观察腕部相机中的耳机壳。只处理earbud_case，连续三帧确认单一目标，使用中心点平滑和40像素中心容差。未检测到目标时立即清除目标；多个候选时不选定目标。输出像素偏差和时间戳，不输出机械臂动作。

脚本：scripts/observe_target.py。Jetson复用an-project的Python/Torch与项目独立Ultralytics依赖，不改环境。

当前阶段为视觉观察模式，没有串口访问。保存的grasp_clearance_v4姿态只是关节参考，不是已标定的空间最低高度，也未完成通电间隙验证。不能把肘关节角度阈值当作末端Z高度保护。自动低头需要先验证运动学或受限运动范围；建议先在现场确认的固定俯视姿态，只测试底座左右跟踪。丢失目标后先停止跟踪，自动搜索扫动需单独验证范围。

## 当前运行方式：YOLO＋深度

用户决定VLM留到PC端，Jetson当前运行scripts/dual_model_observer.py。不加载Qwen、Transformers或bitsandbytes。专用检测使用earbud_container.pt，深度使用Jetson已有的yolo26n-depth.engine。界面显示实时RGB、目标框与深度图；latest.json类状态与vision.jsonl中有像素误差、目标框内中心区域深度预测、中央区域深度分位数和主机接收时间。

实测已成功启动两个模型，深度有效像素比例为1.0；当前镜头朝天时目标状态为lost。单次状态采样处理约118ms，不作为正式性能基准。程序不访问串口，allow_lowering和motion_enabled始终为false。Q或关闭窗口释放相机。

三模型尝试因Qwen与检测PyTorch缓存占用导致深度TensorRT引擎内存不足而未跑通本次新界面；用户选择双模型后已退出VLM，停止本次新检测引擎构建。原PT和既有深度引擎保留，未修改an-project安装。三模型失败不影响此前独立实验中已有的Qwen部署结果。

## 受限低头测试

lookdown_prefix.py使用原示教0–160帧，半速且不超过该终点；读取最新检测/深度结果，检测到目标或深度/数据新鲜度异常时停止更新目标并保持关节。首次把边缘椅子当成耳机壳，经截图核对后增加边缘排除和后段确认。resume_lookdown.py曾触发单步限制，continue_lookdown_slow.py采用更细时间插值继续既定范围；最终在真实蓝色壳进入视野时停止，截图核对正确。动作中只有视觉触发的停止，尚未实现机械臂持续追踪。

历史编码器实测有最多数个计数的限位边缘超调；代码对下发目标仍严格限制原范围，只允许在5计数以内的实测恢复误差且目标朝限位内。此规则不等于空间高度约束。
